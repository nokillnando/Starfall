Sometimes when spawning, the cubemap might not load correctly, just give the chip a little nudge / change positions

Specular in source works as the following so mod your texture accordingly:

The whiter it is, the shinier it will be, the same way that the blacker, more rought it will be, which is the inverse of PBR, using metallic / roughness maps, is
as far as I am aware, impossible, you'll have to mix and play around with specular to have the desired effect. Or play with an inverse roughness and metallic texture.

Furthermore, if you want to use bumppmaps with specular mask, you'll have to use it as an alpha channel of the basetexture then add a special flag for it
Dont try to use a bumpmap with alpha channel, its not properly supported in gmod, if you try, your model will have its lighting fullbright

If you dont want a specular mask, basetexture and bumpmaps work together as they should

Otherwise perhaps try exporting parts that should be more shiny or not, separately, and adjust how much the cubemap affects them when loading the mesh

    Explaining of each possible config, not in order:
    
    mdl,----------------------------The actual mesh obj URL ~21.845 tris max per object (it multiplies by 3, which is about 65536 verts max), also MUST be triangulated, 
    beware of rendertarget limit as well, around ~20 by default, that means about ~20 meshes per time if using single texture, should be enough as long as you stay at the tris limit
    you can load multiple meshes per .obj, that way it may pass the tris limit, but individual meshes are limited still

    ColorAndAlpha,------------------Self explanatory, RGB Alpha, can be used for custom texture as well
    UseEnvMapSpecularReflections,---Enables specular reflections, if true or if false will disable all kinds of reflections, loading an in-game material (not texture) overrides this
    EnvMapShinyness,----------------How much the specular affects reflections, also works as a tint
    EnvMapLink,---------------------The mask texture itself, uses a URL
    BumpMapLink,--------------------The bumpmap URL
    UsePhong,-----------------------1 or 0, for the following look at valve wiki, they are mostly useful for when you dont use a mask
    InvertPhongMask,----------------Try playing with this
    PhongTint,----------------------exactly as name says
    PhongBoost,---------------------Only works with normalmap - Spec Boost
    PhongExp,-----------------------Spec Glossiness
    UseRimLight,--------------------1 or 0, works only with BaseMapAlphaPhongMask?
    RimLightBoost,------------------A value, see valve wiki, only works with having a normalmap
    RimLightExp,--------------------Same as above
    EnvMapContrast,-----------------Used with BaseMapAlphaEnvMask
    EnvMapSaturation,---------------Same as above, try fiddling with these

    TextureScale--------------------Same as above, also sets bumpmap scale

    EnableBaseMapAlphaEnvMask-------Same as above but for EnvMask, use either of one, not both at the same time
    EnableNormalmapAlphaEnvMapMask--Same as the above, but instead will use from the NormalMap, might have issues related to Starfall itself, due to how RT works
    PhongAlbedoTint-----------------Try fiddling
    PhongExponentTexture------------Self explanatory, although im not really sure if it even works
    PhongAlbedoBoost----------------Try fiddling
    Flags = {}----------------------Material flag numbers, see valve wiki, the order affects it
    LowPolyTexture------------------Linear texture filtering, PS1 style
    Color2--------------------------Vector, think of it as a extra color brightness if needed
    SuppressEngineLighting----------Make it fullbright
    Shader--------------------------Shader to create (defaults to "VertexLitGeneric", can be "Modulate", "UnlitGeneric", etc.)

    BlendTintByBaseAlpha------------Bool (true/false), enables tinting via base texture alpha mask ($blendtintbybasealpha)

    DetailTint----------------------Vector, color tint for the detail texture

    FixAngles = { pitch=false, yaw=false, roll=false, invert=false } -- Set axes to lock to AngleFixTarget's world rotation. Use invert=true for mirrored wheels (like right-side calipers).

    ColorCommand--------------------String (e.g. "Body"), enables chat-activated color/phong/reflection adjustments (e.g. typing "!Body 255 0 0" in chat while looking at the car).     Variant-------------------------Int (e.g. 1, 2, 3), variant index for this part. Only the active variant is rendered. Switchable via !part or !booth!

    Chat Commands:
    !booth                 - Opens/closes the interactive Configurator menu (checks sight/vehicle)
    !savepreset <name>     - Saves current vehicle colors, parts, and overrides to Starfall disk
    !loadpreset <name>     - Loads a previously saved preset
    !listpresets           - Prints all available presets for this vehicle to console
    !delpreset <name>      - Deletes a saved preset
    !part <name> <var>     - Changes active part variant (e.g. "!part Spoiler 2", or "!part Spoiler none" / 0 to remove)
    !swap <name> [value]   - Activates a texture swap or skin (e.g. "!swap Skin 2", "!swap RotorGlow 1.0", "!swap FogLights")
    
    
    =============================================================================
    BODYKITS & SWAPPABLE PARTS SYSTEM (Part & Variant):
    =============================================================================
    You can group any number of submesh entries into swappable bodykit options
    by tagging them with "Part" and "Variant" inside the `meshes = { ... }` table:
    
      Part    = "PartGroupName"   -- Name of the category (e.g. "Spoiler", "Hood", "Exhaust")
      Variant = 1                 -- Variant number (1 = default/stock, 2 = custom, 3 = race, etc.)
    
    How it works:
    1. When the vehicle spawns, Variant 1 is automatically visible; all other variants (2, 3, etc.) are hidden.
    2. In-game, open "!booth" -> Tab 4 (Bodykits & Parts) to cycle between variants with [<] [>] buttons.
       You can cycle down to "None (Off)" to completely remove/hide any part in real-time!
    3. Or type in chat: "!part <PartName> <VariantNumber>" (e.g. "!part Spoiler 2", or "!part Spoiler none" / "!part Spoiler 0" to remove).
    4. Any submesh WITHOUT a "Part" tag is considered a permanent base mesh and will ALWAYS remain visible.
    5. A single variant can contain multiple submeshes (e.g. a GT Wing made of Blade + Mounts).
    
    -----------------------------------------------------------------------------
    HOW TO MAKE PARTS OPTIONAL (e.g. Starting with NO spoiler on spawn):
    -----------------------------------------------------------------------------
    If you want the vehicle to spawn WITHOUT a spoiler by default, but still have
    the option to add/equip one in the Configurator:
      • Simply DO NOT define a mesh for Variant 1!
      • Start your spoiler options at Variant 2 (e.g. OEM Spoiler = 2, GT Wing = 3).
      • Because Variant 1 is empty, the car will spawn wingless by default!
      • When you open !booth -> Tab 4, cycling to Variant 2 equips the OEM Spoiler,
        Variant 3 equips the GT Wing, and cycling to None/Variant 1 removes it!
    -----------------------------------------------------------------------------

    ColorCommand Chat Commands:
    
    If you define "ColorCommand = 'CommandName'" on a mesh, the vehicle owner looking at the vehicle can type
    "!CommandName [arguments]" (or /CommandName) in chat to dynamically recolor that mesh and its materials.
    
    Arguments are separated by the pipe character "|" and support the following options:
    
    1. Base Color (Segment 1 - Required):
       - What it does:
         Sets the base diffuse/albedo color of the hologram/mesh and its material (ColorAndAlpha).
       - Hex Format: "#RRGGBB" or "#RRGGBBAA" (e.g. #FF0000 or #FF0000FF)
       - RGB Format: "R G B" or "R, G, B" (can be 0-255 integers or 0.0-1.0 floats, e.g. 255 0 0 or 1 0 0)
       - RGBA Format: "R G B A" or "R, G, B, A" (e.g. 255 0 0 255)
       
    2. Specular Tints (Optional Segments):
       - What it does:
         Overrides/tints the color of specular highlights (phong) and environmental reflections (envmap).
         Tints are parsed using Hex, RGB, or RGBA formats (same as base color).
       - Logic & Variables Affected:
         - If you provide ONE additional color segment, it tints BOTH Phong ($phongtint) and EnvMap ($envmaptint).
           Example: "!CommandName #FF0000 | #0000FF" (Red paint with Blue specular highlights and reflections)
         - If you provide TWO additional color segments, the 1st tints Phong ($phongtint), and the 2nd tints EnvMap ($envmaptint).
           Example: "!CommandName #FF0000 | #0000FF | #00FF00" (Red paint, Blue specular highlights, Green reflections)
       
    3. Specular Multipliers (Optional Segments - Numbers or Percentages):
       - What it does:
         Boosts or dims the intensity of phong highlights (specular brightness) and envmap reflections (shininess).
       - Formats:
         - Can be percentages (e.g. "150%" or "150" - values > 2 are divided by 100).
         - Can be multipliers (e.g. "1.5" or "0.5" - floats <= 2.0).
       - Logic & Variables Affected:
         - If you provide ONE numeric segment, it scales BOTH Phong and EnvMap intensities.
           Example: "!CommandName #FF0000 | 150%" (Red paint, 1.5x brighter specular highlights and reflections)
         - If you provide TWO numeric segments, the 1st scales Phong ($phongtint multiplier), and the 2nd scales EnvMap ($envmaptint multiplier).
           Example: "!CommandName #FF0000 | #0000FF | 1.5 | 50%" (Red paint, Blue specular highlights, 1.5x phong boost, 0.5x reflection envmap boost)
    
    
    Texture swap examples:
    
     IMPORTANT: All swaps for a specific mesh MUST be defined inside ONE single 'TextureSwaps = { ... }' table!
     Do NOT create multiple 'TextureSwaps = { ... }' blocks inside the same mesh.

     TextureSwaps = {
         ["Brake"] = {
             texture = "url here",
             highlight = false,
             color = Color(255, 0, 0, 255),
             dynamic = true,
             dynamicMin = 0,
             dynamicMax = 300,
         }
     }
    
     Example 2: Comprehensive Multi-Swap Suite (All in ONE table)
    TextureSwaps = {
        ["RunningLights"] = { 
            input = "Lights", -- Optional: Use a specific Wire input name instead of the table key
            priority = 1,     -- Low priority
            highlight = true,
            color = Color(150,0,0,255)
        },
        ["BrakeLight"] = { 
            input = "Brakes",
            priority = 2,     -- Higher priority: Overwrites "RunningLights" if both are on
            highlight = true,
            color = Color(255,0,0,255)
        },
        ["Skin_Red"] = {
            input = "Skin",   -- Multiple swaps can share one input
            condition = 1,    -- Only activates if the "Skin" input value is exactly 1
            texture = "url_for_red_texture",
            PhongBoost = 2.5,                 -- Custom specular boost when this skin is active
            EnvMapShinyness = Vector(0.1, 0.1, 0.1), -- Custom reflection intensity
        },
        ["Skin_Blue"] = {
            input = "Skin",

            PhongBoost = 1.0,

        ["Carbon_Mode"] = {
            input = "Carbon",
            texture = "url_for_carbon_weave",
            PhongBoost = 3.0,
            PhongExp = 256,

    =============================================================================
    The mesh loader automatically detects spinning parent props (e.g. ACF/Base wheels)

    Parameters per mesh:
      WheelBlurTexture = "https://i.imgur.com/rim_blurred.png"  -- URL or local material to use at speed
      WheelBlurRPM     = 350                                     -- RPM / angular velocity threshold (default: 300)
    
    Wheel Setup Example:
        {
            mdl = "models/mycar/wheel_front_left.obj",
            texture = "https://i.imgur.com/rim_static.png",
            WheelBlurTexture = "https://i.imgur.com/rim_blurred.png",
            WheelBlurRPM = 280,
            Parent = "Wheel_FL",
            Shader = "VertexLitGeneric",
            PhongBoost = 2.0,
        }

    =============================================================================
    DOWNLOADING IMAGES vs STREAMING (DownloadImages & DownloadImage):
    =============================================================================
    • Global setting: `local DownloadImages = true` (downloads .png/.jpg textures to
      `data/sf_filedatatemp` to bypass Starfall's RenderTarget limits).
    • Per-Submesh override: You can add `DownloadImage = false` or `DownloadImage = true`
      inside any submesh entry in `meshes = { ... }` to force or skip saving that specific
      texture to disk temp!
      
      Example:
        {
            mdl = "models/mycar/interior_gauges.obj",
            texture = "https://i.imgur.com/gauges.png",
            DownloadImage = false, -- Skips disk download; uses direct live URL streaming
        }

    =============================================================================
    SHADER TYPE vs SUPPRESS LIGHTING (HIGHLIGHT):
    =============================================================================
    • Shader = "VertexLitGeneric":
      Standard Source engine 3D shader with full diffuse, Phong specular highlights,
      normal mapping ($bumpmap), and cubemap reflections ($envmap).
    
    • Shader = "UnlitGeneric":
      Emissive 2D/3D shader that is completely unaffected by world light/shadows (fullbright).
      (Note: UnlitGeneric does NOT calculate Phong or normal maps).
      
    • SuppressEngineLighting = true (or `highlight = true` in TextureSwaps):
      Disables environmental shadow shading on a "VertexLitGeneric" mesh, forcing it to
      render at full brightness while PRESERVING your Phong specular and reflection maps!
      - Perfect for: Headlights, Daytime Running Lights (DRLs), illuminated dashboards,
        and glowing brake rotors.
    =============================================================================

local function mergeConfig(userConfig)
    if not userConfig.mdl then
        error("MDL parameter is required")
    end
    
    local defaultConfig = getDefaultConfig()
    local finalConfig = table.copy(defaultConfig)
    
    -- Merge everything from user config, overwriting defaults or adding new params
    for k, v in pairs(userConfig) do
        if type(v) == "table" and k ~= "Flags" and k ~= "ColorAndAlpha" then
            finalConfig[k] = table.copy(v)
        else
            finalConfig[k] = v
        end
    end
    
    -- Normalize Part and Variant casing
    if userConfig.part ~= nil then finalConfig.Part = userConfig.part end
    if userConfig.variant ~= nil then finalConfig.Variant = tonumber(userConfig.variant) or 1 end
    if userConfig.Part ~= nil then finalConfig.Part = userConfig.Part end
    if userConfig.Variant ~= nil then finalConfig.Variant = tonumber(userConfig.Variant) or 1 end
    
    -- Handle native Pearlescent paint setup
    if userConfig.Pearlescent and type(userConfig.Pearlescent) == "table" then
        local baseCol = userConfig.Pearlescent.base or Color(255, 255, 255, 255)
        local shiftCol = userConfig.Pearlescent.shift or Color(0, 255, 120, 255)
        local intensity = userConfig.Pearlescent.intensity or 1.5
        finalConfig.ColorAndAlpha = baseCol
        finalConfig.PhongTint = Vector(shiftCol.r / 255, shiftCol.g / 255, shiftCol.b / 255) * intensity
        finalConfig.EnvMapShinyness = Vector(shiftCol.r / 255, shiftCol.g / 255, shiftCol.b / 255) * (intensity * 0.05)
    end
    
    return finalConfig
end

-- Process the meshes table to add defaults
local function processMeshesTable(meshesTable)
    local processedMeshes = {}
    for i, meshConfig in ipairs(meshesTable) do
        processedMeshes[i] = mergeConfig(meshConfig)
    end
    return processedMeshes
end

if CLIENT then
    net.receive("sendMeshToClient", function()
        local recipient = net.readEntity()
        local meshIndex = net.readInt(16)
        
        if meshes[meshIndex] and meshes[meshIndex].meshData then
            net.start("sendMeshData")
            net.writeInt(meshIndex, 16)
            net.writeStream(meshes[meshIndex].meshData)
            net.send(recipient)
            
            if debugPrints then print("Sending mesh ", meshIndex, " to ", recipient:getName()) end
        end
    end)

    net.receive("sendMeshData", function()
        local meshIndex = net.readInt(16)
        net.readStream(function(data)
            if meshes[meshIndex] and not meshes[meshIndex].meshData then
                meshes[meshIndex].meshData = data
                
                if debugPrints then print("Received mesh ", meshIndex, " from another client, size: ", math.round(#data / 1048576, 3) .. "mb") end
            end
        end)
    end)

else -- SERVER
    local clientMeshes = {}

    net.receive("reportMeshStatus", function(_, ply)
        local status = net.readTable()
        clientMeshes[ply] = status
    end)

    net.receive("requestMissingMeshes", function(_, ply)
        local missingIndices = net.readTable()
        for possibleSender, status in pairs(clientMeshes) do
            if possibleSender ~= ply and isValid(possibleSender) then
                for _, index in ipairs(missingIndices) do
                    if status.completed[index] then
                        net.start("sendMeshToClient")
                        net.writeEntity(ply)
                        net.writeInt(index, 16)
                        net.send(possibleSender)
                        
                        if debugPrints then print("Requested client ", possibleSender:getName(), " to send mesh ", index, " to ", ply:getName()) end
                        break
                    end
                end
            end
        end
    end)
end

hook.add("removed", "stopStreams", function()
    if net.isStreaming() then
        net.cancelStream()
    end
end)
